A statement is an **isotope** of another when it has the same element (the intent) and a different mass number (the number of latent components attached).

## The element is invariant

For the *Open Arms* hub, the element is invariant across every rendition:

```text
Z = "the artist maintains a mutual-aid relation with his community"
```

| Isotope | Mass number | Components | Citable? |
| --- | --- | --- | --- |
| Z-0 | 0 latent | runs a community-forward profile | yes, asserted |
| Z-1 | 1 latent | *plus*: hub links a crowdfunding campaign for a third party | yes — about **what he links** |
| Z-2 | 2 latent | *plus*: the subject's condition and figures | **never asserted** — retained only |

The metaphor earns its keep at exactly one point: **neutrons add mass without adding charge.** The latent component increases retrieval mass (a query about the artist's community role should surface this node) while contributing no assertion.

## What rotation is not allowed to do

Rotation **relocates a permitted but sensitive fact** — it is not a permission grant. If rotating a claim changes *what it is about*, it has become a different element and must be modelled as a different anchor, not a rotation. That is the boundary that keeps this from being a laundering device.
