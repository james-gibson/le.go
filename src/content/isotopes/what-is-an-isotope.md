An **isotope** is a named, liftable system. It is the le.gume unit for *"a minimal viable system you can lift into your own garden."*

## Same element, different mass

In chemistry, isotopes of an element have the same **element** (the intent) and a different **mass number** (the number of latent components attached). le.gume borrows that verbatim:

| Term | Meaning |
| --- | --- |
| **element** | the invariant intent — *what the system is for* |
| **mass number** | the count of latent components it carries |

Neutrons add mass without adding charge. A latent component increases retrieval mass while contributing no assertion — which is exactly how a sensitive fact can stay retrievable without being asserted.

## Named after pickles, never numbered

An isotope is **named after a pickle** (`silverskin`, `cornichon`, `pearl`, `piccalilli`), never numbered. The name is the URL, the QR payload, and the prompt. A number would imply an order; a pickle name implies a flavour — and two isotopes are comparable by their **`presumes:`** line (runtime, platform, permissions), not by their rank.

## The shape of an isotope page

Every isotope page runs the same five beats:

| Beat | The question it answers |
| --- | --- |
| **What it proves** | why this system exists |
| **The parts** | the pieces, as a table |
| **What it costs** | the honest price |
| **Take this, not that** | the liftable decision |
| **What would break it** | the failure mode you inherit |

An isotope also declares **`slots:`** — the parameters a reader must decide before lifting it — and carries an **Agent prompt** block so a future agent can reconstruct it.

## How le.go uses it

le.go's own isotope is **Silverskin** (the seed deploy). Within le.go's domain, the artist's mutual-aid fundraiser edge is modelled as an isotope too:

| Isotope | Mass | Components | Citable? |
| --- | --- | --- | --- |
| Z-0 | 0 latent | runs a community-forward profile | yes, asserted |
| Z-1 | 1 latent | *plus*: hub links a crowdfunding campaign for a third party | yes — about **what he links** |
| Z-2 | 2 latent | *plus*: the subject's condition and figures | **never asserted** — retained only |

Rotation relocates a permitted-but-sensitive fact; it is not a permission grant. If rotating a claim changes *what it is about*, it has become a different element and must be modelled as a different anchor.
