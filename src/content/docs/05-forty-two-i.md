Here is where the Douglas Adams joke stops being a joke and becomes a coordinate system. `le.go` is the introduction; the canonical system lives in the lab (`isotope`, `lezz.go`, `lab-safety`), and this page is the doorway.

## The premise, in four snaps

| Piece | The move | What it means |
| --- | --- | --- |
| `null` | leave the hole empty | absence is **no plane** — never a value you can put in the graph |
| `not null` | the hole is a piece | *"null exists"* is itself a fact; unknown ≠ absent |
| `0 > 1` | a silent zero outranks a spoken one | a zeroed field is a *claim* that disconnects the graph (`ErrDisconnected`) |
| `42 = 0` | every universe agrees where zero sits | `42` is the shared origin — **a coordinate, not a credential** |

## 42 is a coordinate, not a credential

`42 + 0i` is the **seed-42 ground truth** — the nominal. Every load-bearing claim meets on `42`, and it is where you measure *from*. It is not the answer to an unasked question, and it is not a badge you earn.

The `42i` part is the **distance** — how far a claim has drifted from nominal, along the imaginary axis, against linear time. One measure, regardless of source: a stale citation, a misattributed uploader, a spoken grant nobody recorded.

## The four registers

| Rotation | Position | Meaning |

| R⁰ | `42 + 0i` | seed-42 ground truth — proven consensus |

| R² | `−42 + 0i` | contradiction — the sign flips (i² = −1) |

Anchors are exactly `42` or `42i` — never `42i²`. Rotation count is metadata, never a plane label.

## Charges, and why `0` is forbidden

Charges are integer **symmetry labels**. An edge is admissible only when the phases cancel:

```text
q_a + q_b = 0
```

A lone `+1` is a half-edge that cannot enter the mesh — not by policy, but by construction. And a **neutral** charge is worse: `charges "1,-1,0"` fails with a disconnected graph. A zeroed field is not "neutral"; it is a claim that the graph cannot hold.

So the ladder is:

```text
null → null exists → 0 is not null → -1 < 0 < 1
```

- **`null`** is *no plane*. Absence is the correct representation of "unknown", not a zero-valued entry.
- **`null exists`** is itself a fact — the empty spot is information.
- **`0 is not null`** — a zeroed field is a claim, and the graph rejects it.
- **`-1 < 0 < 1`** — magnitudes live in the weights; phases must cancel.

## Casting shadows back

Because the complex tuple is stored, projecting to Chicago, MLA, APA, BibTeX, or `/bare/` is matrix multiplication with punctuation templates. **The projector casts those shadows faithfully — it does not fix them.** Only the 42i brief rotates the citation, and that is the only output that does.

Nothing is lost until you ask for a flat shadow, and you can cast a fresh shadow whenever an editor asks.
